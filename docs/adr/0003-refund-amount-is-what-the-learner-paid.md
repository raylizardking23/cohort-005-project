# The Refund Amount is what the learner actually paid

The Refund Amount is always the amount on the Personal Purchase, after any discount, coupon or purchasing-power price, never the course's list price. The earlier code refunded the list price unless a purchasing-power price applied, so a learner who used a coupon was promised more back than we took, and the email and the settings page showed different amounts for the same request. The list-price rule looked deliberate, so this records that it was reversed on purpose.
